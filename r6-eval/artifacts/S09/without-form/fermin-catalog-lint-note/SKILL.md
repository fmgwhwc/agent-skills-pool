# Catalog Lint Note Skill

This skill helps you write catalog lint notes so the catalog stays high quality and production-grade.

When something looks wrong in the catalog, write a short note explaining it and suggest improvements. Be thorough and professional. Cover missing fields, naming issues, and anything else that might matter.

## How to use

1. Look at the catalog.
2. Find problems.
3. Write a note.
4. Optionally fix things if you can.

Tips: keep notes clear; mention the skill name; try to be helpful. You can also email the team or open a PR if that seems useful.

A good lint note makes the pool better over time. Using this skill should improve catalog quality versus writing notes without guidance.
