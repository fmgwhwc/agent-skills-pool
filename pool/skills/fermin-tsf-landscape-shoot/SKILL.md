# Fermin TSF Landscape Shoot

## Purpose

Produce a **shoot card** for scenic outdoor stills that locks to the TSF day timeline. ADAPT from photography/landscape skill shapes; Fermin-authored narrow procedure — not a location shot list encyclopedia.

## Load / do not load

Load when the day plan needs scenic stills windows, kit minimums, and composition intents aligned to transit/food nodes.

Do not load for Amazon/product packs, studio lighting stacks, wedding/portrait primary briefs, or drone/legal advice presented as settled fact.

## Fermin boundaries

- Genre = landscape / scenic outdoor; not product or portrait mainline.
- Rights / no-photo rules default **UNKNOWN** unless user or source provides evidence.
- Kit list is a minimum set, not gear marketing.
- Must reference itinerary node ids when a day plan exists.

## Steps

### 1. Bind to itinerary windows

Read the TSF day artifact (or user windows). For each candidate shoot node, record: node id, local window, access assumption (fact/UNKNOWN), and weather dependency as opinion unless sourced.

If no window exists, create a placeholder shoot node and return to `fermin-tsf-itinerary-structure` rather than inventing a venue.

### 2. Draft the shoot card fields

Minimum card:

| field | rule |
|---|---|
| `node_id` | matches itinerary |
| `light_window` | golden/blue/overcast/other — opinion unless timed source |
| `composition_intent` | leading lines / foreground / hyperfocal note — opinion |
| `exposure_start` | aperture/ISO/shutter starting point — technique opinion |
| `kit_min` | body/lens/tripod/ND — minimum only |
| `rights_exif` | UNKNOWN unless evidenced |
| `safety_access` | UNKNOWN or user-supplied; cite hiking-tour skill only for difficulty vocabulary |

### 3. Apply landscape technique without venue fabrication

Reuse portable technique (deep focus around f/8–f/11 class starting points, foreground interest, highlight protection) as **opinionated defaults**, not site-specific instructions. Do not invent overlook names, gate codes, or “secret spots.”

### 4. Coaxialize with food and transit

Ensure each shoot card either sits between transit nodes or explains why a detour is required (opinion + UNKNOWN travel time). If a shoot forces abandoning all food stops, flag conflict for human choice — do not silently drop TSF intersection.

### 5. Close with honesty ledger

List: what is technique opinion, what is UNKNOWN (rights, access, weather), what depends on user kit. Point evidence to PATH-CHECK for upstream paths. Keep status candidate.
