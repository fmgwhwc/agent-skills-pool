# Gate 3 · 接受门

结论边界、知识质量、教学价值、可发布性。执行者：**Human / Reviewer**。

## 结论选项

| 结论 | 含义 |
|---|---|
| 接受 | 可议晋升 L3→L4 流程 |
| 有条件接受 | 列出必须补丁后再跑 Gate2 |
| 退回 | 不进入 Validated / Production |

## 纪律

- Gate2 未过 → 不得接受为 Production
- Skills `catalog.yaml` 条目增加 ≠ 物料被接受
- 过程复盘写入 `retrospectives/`；R6 证据仍留在 `r6-eval/`
